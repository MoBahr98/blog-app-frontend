# 📰 Modern Blog Platform (Frontend)

A full-featured **React + Vite + Tailwind CSS** web application built as part of a complete MERN project.  
This frontend delivers a clean, responsive UI with markdown support, AI-powered post generation, and secure integration with the backend API.

---

## 🚀 Features

1. **Authentication** – Secure Sign Up & Login using JWT (via backend API).
2. **Blog CRUD** – Create, edit, delete posts with optional cover image and unique slug URLs.
3. **Markdown Support** – Write and preview blogs in markdown with syntax highlighting.
4. **AI Blog Generator** – Automatically ideas, summaries, full posts, and comment replies and full markdown posts using AI (Gemini API).
5. **Tag Filtering** – Categorize posts by tags such as *Technology*, *Science*, *Economy*, *Politics*, and *Education*.
6. **Search Functionality** – Search posts by title or content in real-time.
7. **Admin Dashboard** – Manage blog posts, drafts, and comments.
8. **Post View Counter** – Track how many times each post has been viewed.
9. **Comments & Engagement** – Readers can like and comment on posts.
10. **Draft & Publish Toggle** – Save drafts or publish posts instantly.
11. **Responsive UI** – Fully optimized for both desktop and mobile.
12. **Dynamic Slug Routing** – Posts are accessible through clean, SEO-friendly URLs.

## 🧩 Tech Stack

| Category | Technologies |
|-----------|---------------|
| **Framework** | React 19 + Vite |
| **Styling** | Tailwind CSS |
| **Routing** | React Router DOM v7 |
| **Markdown Rendering** | `@uiw/react-md-editor`, `@uiw/react-markdown-preview`, `remark-gfm` |
| **Charts** | Recharts |
| **Icons** | React Icons |
| **HTTP Requests** | Axios |
| **Date Handling** | Moment.js |
| **Notifications** | React Hot Toast |

## ⚙️ Setup Instructions

### 1. Clone the repository
```bash
git clone https://github.com/MoBahr98/blog-app-frontend.git
cd blog-app-frontend
```
### 2. Install dependencies
```bash
npm install
```
### 3. Run the development server
```bash
npm run dev
```
## Dev notes

- This project uses Vite for fast builds and hot reloading.

- Tailwind CSS is used for styling with a modern, utility-first approach.

- The AI integration uses the Gemini API for generating blog ideas and markdown drafts.

- Each post includes tags, a view counter, and optional comments for engagement.

- The frontend communicates with a separate Express/MongoDB backend (see blog-app-backend).
